# DVC: Vine Copulas

This project provides a production-ready implementation of vine copulas with PyTorch and TensorFlow backends. It includes nonparametric and parametric pair copulas, structure construction (C-/D-/R-vines), density evaluation, entropy and mutual information estimation, conditional prediction, sampling, and a time-dependent module.

Contents:
- Overview and structure
- User guide (fitting, evaluation, time-dependent modeling, performance)
- API reference
- Development guidelines
